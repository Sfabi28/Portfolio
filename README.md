# 📟 Sfabi28 Terminal Portfolio

> A minimalist, terminal-style portfolio website built with vanilla HTML, CSS, and JavaScript.

![Screenshot](https://via.placeholder.com/800x400?text=Metti+qui+uno+screenshot+dopo)

## 🔗 Live Demo
👉 **[Click here to visit the site](https://sfabi28.github.io/NOME_DELLA_TUA_REPO)**

## 🛠️ Tech Stack
* **HTML5** (Structure)
* **CSS3** (Styling & Animations)
* **Vanilla JavaScript** (Command parsing & DOM manipulation)
* **No Frameworks** (Pure coding)

## ⌨️ Features
* **Command Line Interface:** Fully functional command parser.
* **History:** Command history navigation with `Arrow Up` / `Arrow Down`.
* **Tab Completion:** (Coming soon...)
* **Mobile Responsive:** Works on phone browsers.

## 🚀 How to run locally
Just clone the repo and open `index.html` in your browser.
